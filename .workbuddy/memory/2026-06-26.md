# 2026-06-26 工作日志

## Bug 修复: paste_capture 组件无法加载
- **问题**: Streamlit 自定义组件 `paste_capture` 加载失败，导致 Cmd+V 粘贴图片功能不可用
- **根因**: `frontend/index.html` 从 `unpkg.com` CDN 加载 `streamlit-component-lib@2.0.0`，运行环境可能因网络策略/代理拦截了外部 JS 资源
- **修复**: 将 CDN 依赖替换为内联实现 —— 在 `<head>` 中直接定义 `window.Streamlit` 对象（基于 postMessage 协议），彻底消除外部网络依赖
- **修改文件**: `components/paste_capture/frontend/index.html`
