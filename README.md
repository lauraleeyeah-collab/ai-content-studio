# 小红书爆款拆解与选题文案生成工具（Multi-Agent）

> 🚀 已升级为「AI 超级自媒体工具」（M1 图文工厂 + M2 视频工厂 + M3 渠道中心 + M4 数据中心，全部落地）。
> 产品规划见 `docs/PRD-AI超级自媒体工具.md`，调研依据见 `docs/调研报告-2026平台生态与AI趋势.md`。
> 定位：一次生产，多平台适配，数据反哺。核心差异化是「渠道中心」——按平台规则改写而不是复制粘贴。



一个 **5-Agent 流水线 + 5 大内容分析模块** 的小红书内容创作工作台：把热点笔记拆解成可复用的爆款套路，再结合账号人设自动生成选题和文案。

核心设计原则：**LLM 负责判断，Python 负责计算**。模型的打分、排序、比例核验、等级判定等关键环节全部由确定性代码兜底，保证结果可复现、可解释、可审计。

> 这是求职作品集项目，支持 **演示模式**：不需要 API Key 也能 30 秒跑通完整流程，适合面试现场演示。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| **热点选题流水线** | 5-Agent 串联：采集结构化 → 5 维打分筛选 → 爆款拆解 → 选题生成 → 文案生成，每步可人工检查编辑 |
| **笔记爆款分析** | 7 维度评分 + 雷达图可视化 + S/A/B/C/D 等级判定 + 改进优先级排序 |
| **竞品账号分析** | 代码计算互动率/发布规律/内容分布 + LLM 定性分析，输出可执行的运营建议 |
| **热门内容趋势** | 标签共现图谱 + 趋势统计 + LLM 洞察（内容空白、爆款公式、战略总结） |
| **内容创作辅助** | 标题优化（生成+多维度评分）、A/B 测试、标签组合推荐、文案诊断 |
| **历史记录管理** | 全部历史数据的查看/复用/删除，让每次分析沉淀为运营资产 |
| **图文工厂（M1）** | 选题 → 搜索词 → 标题(关键词前20字检查) → 封面提示词 → 正文平台改写 → 互动话术，全流程确定性校验 |
| **视频工厂（M2）** | 选题 → 秒级分镜脚本(时间轴校验) → 视频标题/封面 → 播放优化(收藏指令检查) → 互动策略 |
| **渠道中心（M3）** | 6 平台规则库(可编辑) → 一键多平台改写(含改写理由) → 双重合规检查 → 发布清单导出(强制AI标注确认) |
| **数据中心（M4）** | 数据回填(手动/CSV) → 渠道对比看板 → 爆款归因(代码归一化+LLM解读) → 历史管理 |

## 5-Agent 流水线

```
用户粘贴原始笔记内容
   ↓
Agent0 采集/结构化 —— 把杂乱文本解析成标准字段（数字单位换算、标签提取、类型判断）
   ↓
Agent1 热点筛选 —— 模型给 5 维度主观打分，代码负责算总分、排序、低质预警
   ↓
Agent2 爆款分析 —— 拆解标题公式/内容结构/情绪触发点/互动话术/可复制性
   ↓
Agent3 选题生成 —— 借鉴溯源 + 人设适配 + 历史去重，代码核验内容形式比例
   ↓
Agent4 文案生成 —— 按风格特征说明（style_guide）生成图文或视频文案
```

## 设计亮点（面试可展开讲）

1. **确定性兜底**：`Agent1` 的 5 维打分加总/归一化/平局排序、`Agent3` 的视频图文比例核验、`Note Scorer` 的加权总分/等级判定，全部由 Python 代码计算，模型只做主观判断，杜绝 LLM 算数不稳定问题。
2. **失败防御**：单条数据缺失字段自动跳过并降级置信度；整批低分触发 batch_warning 而不是静默凑数；JSON 解析三级容错 + 自动纠错重试。
3. **成本控制**：竞品分析采样 `Top5 高互动 + 5 条最近 + 5 条随机` 发送给 LLM，趋势分析有 token 预算上限，控制 API 成本。
4. **数据沉淀复用**：选题去重依赖历史库；所有分析结果入库（18+ 张表），支持历史记录管理页面复用。
5. **人设沉淀**：写作风格用 `style_guide_v2.md` 持续迭代，不硬编码在代码里。

## 技术栈

- **前端/交互**：Streamlit（多页面 + 自定义 CSS 组件）
- **模型调用**：阿里云 DashScope（qwen-plus / qwen-vl-plus），OpenAI 兼容模式
- **数据库**：SQLite（免部署、适合个人工具）
- **可视化**：Plotly（雷达图、趋势图、标签共现图）
- **测试**：unittest + mock（离线测试不依赖 API Key）

## 快速开始

### 方式一：演示模式（无需 API Key，推荐先体验）

```bash
pip install -r requirements.txt
XHS_DEMO_MODE=1 streamlit run app.py
```

打开后侧栏会显示「演示模式」开关。开启后所有 AI 调用返回内置的高质量示例结果，一键填入示例笔记即可跑完整个流水线，适合面试演示和离线体验。

### 方式二：真实调用

1. 在[阿里云百炼/DashScope 控制台](https://bailian.console.aliyun.com/)创建 API Key
2. 设置环境变量（也可以在页面侧栏输入）：

```bash
export DASHSCOPE_API_KEY=你的key
```

3. 启动：

```bash
streamlit run app.py
```

## 部署到 Streamlit Community Cloud

1. 把项目推送到 GitHub 仓库（`.gitignore` 已排除本地数据库，不会泄露数据）
2. 在 [share.streamlit.io](https://share.streamlit.io) 选择仓库和 `app.py`，点击 Deploy
3. 在部署页面的 Secrets 里添加：

```
DASHSCOPE_API_KEY = "你的key"
```

## 环境变量

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `DASHSCOPE_API_KEY` | DashScope API Key（也可在侧栏输入） | 无 |
| `QWEN_MODEL_NAME` | 主模型 | `qwen-plus` |
| `QWEN_VISION_MODEL_NAME` | 视觉模型 | `qwen-vl-plus` |
| `XHS_AGENT_DB_PATH` | 数据库路径 | `database/xhs_agent.db` |
| `XHS_DEMO_MODE` | 演示模式（`1` 开启） | 关闭 |

## 已知限制

- 小红书没有开放热点数据 API，`Agent0` 解析的是手动复制粘贴的原始文本（合规方案），不是自动爬取
- `style_guide_v2.md` 需要持续用真实反馈迭代，才能更贴合本人语气
- 截图识别依赖视觉模型，对图片清晰度有要求
